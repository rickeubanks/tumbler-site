# Custom Tumbler Website

A responsive, static landing page for advertising locally engraved 20 oz tumblers through a drive-thru partner. It includes retail pricing, product options, the included accessories, and a local pickup flow. There are intentionally no online purchasing links.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload everything in this project, including the `.github` and `dist` folders.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, choose **GitHub Actions** as the source.
5. Push to the `main` branch. The included workflow will publish the `dist` folder automatically.

## Customize before publishing

- Replace `Custom Tumblers` in `dist/index.html` with your chosen business or product name.
- Replace `your local drive-thru` with the drive-thru name once the partnership is finalized.
- Update prices or ordering wording directly in `dist/index.html`.
- The main photo is `dist/assets/custom-tumblers-hero.png`.

No build tools or dependencies are required. Open `dist/index.html` directly to preview the page locally.
