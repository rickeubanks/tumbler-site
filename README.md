# Custom Tumbler Website

A responsive, static landing page for advertising locally engraved 20 oz tumblers through Don's Drive Thru (2618 Hilliard Rome Road, Hilliard, OH 43026). It includes retail pricing, product options, the included accessories, and a local pickup flow. There are intentionally no online purchasing links.

Live site: https://rickeubanks.github.io/tumbler-site

## Publish with GitHub Pages

1. Open **Settings → Pages** in the repository.
2. Under **Build and deployment**, choose **GitHub Actions** as the source.
3. Push to the `main` branch. The included `deploy-pages.yml` workflow will publish the site automatically.

## Customize

- Update copy, prices, or ordering wording directly in `index.html`.
- The hero photo is `custom-tumblers-hero.png`; the favicon is `favicon.svg`.

No build tools or dependencies are required. Open `index.html` directly to preview the page locally.
